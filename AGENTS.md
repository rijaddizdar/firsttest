# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- **Stage:** early prototype. `README.md` is the product spec (guide animal Penny the Pangolin, the 13-level map, lesson flow, parent account model, privacy rules); update it when product decisions change. `App/` holds a SwiftUI mock-up of the main screens (welcome → grown-up setup → level map → the one playable "Needs & Wants" lesson → code-locked parent dashboard); it is in-memory only, no SwiftData/backend/network yet. `MoneyPals.xcodeproj` (committed) opens and runs directly; it is generated by XcodeGen from `project.yml` — after adding/removing files in `App/`, run `xcodegen generate`. See `docs/RUNNING.md`.
- **Audience is children (6–11):** all kid-facing copy must follow the language and tone rules in `README.md` section 7.
- **Kids Category and COPPA constraints are hard rules:** no third-party analytics, advertising or tracking SDKs, no IDFA, and no child data beyond the table in `README.md` section 9. Only the parent signs in (Sign in with Apple is unavailable under 13).
- **Planned stack:** SwiftUI iOS app (see `README.md` section 8). Full Xcode 27 is installed: build with `xcodebuild -project MoneyPals.xcodeproj -scheme MoneyPals -sdk iphonesimulator -destination "generic/platform=iOS Simulator" build`. Guard iOS-only APIs with `#if canImport(UIKit)` / `#if os(iOS)` so the code also type-checks against the macOS SDK. The **iOS 27.0 simulator runtime is now installed** — the app boots on an iPhone 17 (iOS 27) sim and can be screenshotted (`xcrun simctl boot "iPhone 17"`, `install`, `launch`, `io … screenshot`). Two launch-env hooks drive deterministic captures: `UITEST_ROUTE` jumps to a screen and `UITEST_LESSON_FEEDBACK` (`right`/`wrong`/`complete`) pre-seeds the lesson state; see `docs/RUNNING.md`. Note `simctl io … screenshot` races the app's first committed frame, so a fresh launch can snapshot blank white — capture after a ~3 s settle and retry until the PNG is not a tiny (~70 KB) blank.
- **App name is intentionally absent** from all code/UI pending a trademark search; the `@main` type `MoneyPalsApp` is a placeholder only.

# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- **Stage:** early prototype. `README.md` is the product spec (guide animal Penny the armadillo, the 13-level map, lesson flow, parent account model, privacy rules); update it when product decisions change. `App/` holds a SwiftUI mock-up of the main screens (welcome → grown-up setup → level map → the one playable "Needs & Wants" lesson → code-locked parent dashboard); it is in-memory only, no SwiftData/backend/network yet. `MoneyPals.xcodeproj` (committed) opens and runs directly; it is generated by XcodeGen from `project.yml` — after adding/removing files in `App/` (including `Assets.xcassets`), run `xcodegen generate`. See `docs/RUNNING.md`.
- **Visuals follow the Penny Design System.** `App/Theme.swift` transcribes its tokens literally (palette, type roles, `Radius`/`Border`/`Motion` constants); reuse those constants rather than hard-coding numbers. Hard brand rules: no green lead, no red anywhere, streak icon is a coin (never a flame), flat cream backgrounds (the peach-50% map header is the only tinted band; Penny's speech bubble is the only shadow). Reward/level/answer art are **Fluent Emoji 3D** PNGs in `Assets.xcassets/Icons` via `FluentIcon` (licence in `App/Resources/FLUENT-EMOJI-LICENSE.txt`, credited in the parent area); UI chrome with no Fluent equivalent stays on SF Symbols. Penny renders from placeholder pose images in `Assets.xcassets/Penny` (`PennyView`), pending the commissioned 3D character.
- **Audience is children (6–11):** all kid-facing copy must follow the language and tone rules in `README.md` section 7.
- **Kids Category and COPPA constraints are hard rules:** no third-party analytics, advertising or tracking SDKs, no IDFA, and no child data beyond the table in `README.md` section 9. Only the parent signs in (Sign in with Apple is unavailable under 13).
- **Planned stack:** SwiftUI iOS app (see `README.md` section 8). Full Xcode 27 is installed: build with `xcodebuild -project MoneyPals.xcodeproj -scheme MoneyPals -sdk iphonesimulator -destination "generic/platform=iOS Simulator" build`. Guard iOS-only APIs with `#if canImport(UIKit)` / `#if os(iOS)` so the code also type-checks against the macOS SDK. The **iOS 27 simulator runtime is installed** (iPhone 17 device present): boot with `xcrun simctl`, install the built `.app`, and drive screens for screenshots via the `UITEST_ROUTE` / `UITEST_LESSON_FEEDBACK` env vars (pass through `SIMCTL_CHILD_*`). Cold-launch renders need a generous settle (~6–9s) before `simctl io screenshot`, or you capture a blank frame.
- **App name is intentionally absent** from all code/UI pending a trademark search; the `@main` type `MoneyPalsApp` is a placeholder only.
